Privacy policy

How data is handled in Falcon’s personal VPS backup workflow.

Last updated: November 3, 2026

Purpose and data

Falcon is a personal system operated by its owner, not a public service for other users. It processes selected VPS configuration files and backup metadata to create and manage backups. These files may contain sensitive information.

Google Drive access

Falcon uses Google OAuth 2.0 to authorize rclone to use the Google Drive API on the owner’s account. This access supports uploading, reading, checking, and maintaining backup files, including deleting them when the owner chooses. Access depends on the permissions granted during authorization.

Google user data is used for this backup workflow. Backup data is stored in Google Drive; Google processes it as the storage provider. Falcon does not sell Google user data or use it for advertising.

Encryption and credentials

restic encrypts backup contents on the VPS before upload to Google Drive. OAuth tokens are stored locally in rclone’s configuration on the VPS and are not published on this website. The security of backups and credentials also depends on the owner’s configuration and protection of the VPS and encryption keys.

Retention and deletion

The owner controls how long backups are kept and can remove them from Google Drive using the backup tools or Drive. Retention and deletion depend on the owner’s configuration and actions; no fixed retention period is promised. Google’s own deletion and retention practices may also apply.

Revoking access

The owner can revoke Falcon’s access through the Google Account connections settings. Revoking access stops future authorized Drive operations; it does not itself delete backups already stored in Drive.

Website and infrastructure

This static site is hosted on GitHub Pages. Falcon does not add its own analytics, advertising, or user tracking to the site. GitHub and Google may process technical information according to their own policies when providing hosting and storage.
