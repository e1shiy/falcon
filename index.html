Personal infrastructure / backup

A quieter way to
keep a copy.

Falcon is a personal backup system for a Debian VPS. It creates encrypted copies of server configuration and stores them in the owner’s Google Drive.

Built for one owner. Falcon is not a public service.

01 / The system

How it works

01

Encrypt locally

restic creates encrypted backups of selected server configuration files before they leave the VPS.

02

Store in Drive

rclone transfers the encrypted backup data to the owner’s Google Drive. systemd runs the backup process on a schedule.

03

Maintain and restore

The owner can read, check, restore, and maintain backups as needed.

02 / Access

Why Google Drive?

Google OAuth 2.0 authorizes rclone to access the owner’s Drive for saving, reading, checking, and maintaining backup data. Access is used for the owner’s personal backup workflow.
