# Falcon

A small static information site for Falcon, a personal VPS backup system. It contains no backup data or credentials.

## Files

- `index.html` — application overview
- `privacy.html` — privacy policy
- `style.css` — shared styling

The site uses relative links and can be served directly from the repository root on GitHub Pages, including under `/falcon/`. No build step or dependencies are required. Update the policy when the actual backup or data-handling practices change.
